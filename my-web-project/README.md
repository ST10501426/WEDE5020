# Paradox Store - E-Commerce Website

A modern, responsive e-commerce website for Paradox Store, featuring premium apparel and accessories including T-shirts, hoodies, caps, and bags.

## 🌟 Features

- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **Product Showcase** - Beautiful product displays with multiple image views (front/back, side views)
- **Category Navigation** - Browse products by category with easy filtering
- **Price Filtering** - Filter products by price range
- **Featured Collections** - Highlighted product collections on homepage
- **About Section** - Company story, mission, values, and team information
- **Contact Form** - Customer contact and inquiry submission
- **Professional UI/UX** - Modern design with smooth animations and hover effects
- **SEO Optimized** - Includes sitemap.xml and robots.txt for search engine optimization

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No server-side requirements for static hosting

### Installation

1. **Clone or download the project:**
   ```bash
   git clone https://github.com/yourusername/paradox-store.git
   cd paradox-store
   ```

2. **Open in browser:**
   - Double-click any `.html` file to open directly
   - Or use a local server (recommended):
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Python 2
     python -m SimpleHTTPServer 8000
     
     # Using Node.js (with http-server)
     npx http-server
     ```

3. **Access the site:**
   - Open `http://localhost:8000` in your browser
